# edu-assets

小学生向けWeb教材で共通利用する画像アセット集です。

## バッジ一覧サイト

[Badge Lab を開く](https://tt-sensei.github.io/edu-assets/)

教科別バッジ、エレメント、コレクションバッジを、検索・タグ絞り込み・プレビューで確認できます。

## 主な内容

- 共通バッジ
- 国語・算数・理科・社会バッジ
- エレメントコレクション
- コレクションバッジ

## フォルダ構成

- `assets/badges/`：共通・教科別バッジ
- `assets/elements/`：エレメントバッジ
- `assets/collections/`：コレクションバッジ

各画像は、教材から直接参照して利用できます。
